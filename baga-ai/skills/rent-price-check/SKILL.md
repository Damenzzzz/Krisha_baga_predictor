# Проверка цены аренды и поиск по ремонту (Baga AI)

Навык работает с базой из 7 476 объявлений аренды krisha.kz (Алматы и Каскелен,
собраны 21.09.2026) и моделью цены, обученной на этих данных.

## Когда использовать

- пользователь дал ссылку или id объявления krisha.kz и спрашивает про цену;
- пользователь описывает желаемый ремонт и хочет найти подходящие квартиры;
- нужно сравнить объявление с похожими предложениями.

## Когда НЕ использовать

- другие города (в базе только Алматы и Каскелен);
- продажа квартир (в базе только помесячная аренда);
- вопросы про ипотеку, документы, юридические аспекты сделки.

## Как пользоваться

Все команды запускаются из корня проекта (`baga-ai`).

**Проверить цену объявления** (принимает id или ссылку krisha.kz):

```bash
python scripts/check_listing.py price 1014955701
python scripts/check_listing.py price https://krisha.kz/a/show/1014955701
```

Вернёт JSON: диапазон похожих (p10/p50/p90), вердикт, надёжность оценки,
список аналогов и объяснение, сформулированное LLM по этим аналогам.

**Найти квартиры по описанию ремонта:**

```bash
python scripts/check_listing.py search "светлая кухня в скандинавском стиле" --city алматы --rooms 2 --price-max 400000
```

**Оценить квартиру, которой нет в базе** (например, с другого сайта):

```bash
python scripts/check_listing.py price --area 60 --rooms 2 --city алматы --district "бостандыкский р-н" --floor 5 --floors-total 12 --price 550000
```

## Как отвечать пользователю

1. Назови цену объявления и диапазон похожих: «просят 550 000, похожие сдают за 380–470 тысяч».
2. Дай вердикт словами «выше / в диапазоне / ниже диапазона похожих объявлений».
3. Приведи 2–3 аналога с id и ценами — на них построен вывод.
4. Если в ответе `reliable: false`, обязательно предупреди: похожих объявлений мало,
   оценка ненадёжная.

## Чего нельзя говорить

- **Не говори «вы переплачиваете».** Модель знает цены объявлений, а не цены сделок.
  Правильная формулировка — «дороже похожих предложений».
- Не придумывай характеристики, которых нет в данных: год постройки и тип дома
  в этой базе почти всегда отсутствуют.
- Не переноси вывод на другие города: модель на MAPE 16% в Алматы и 22% в Каскелене,
  за их пределами она не проверялась.

## Точность

Out-of-fold на 7 476 объявлениях: MAPE 16.3%, интервал 10–90 покрывает 80.5% реальных цен.
Рыночный бейзлайн (медиана ₸/м² по району) даёт MAPE 22.3%. Подробнее — в `EVALS.md`.
